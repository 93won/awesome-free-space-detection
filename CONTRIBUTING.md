# Contribution Guidelines

Thank you for helping to grow this list!

## How to add an entry

1. Fork this repository and create a branch.
2. Add your entry to the table of the matching section, keeping the format:

   ```
   | Name | [Paper Title](paper-link) | Venue / Year | [org/repo](code-link) or — |
   ```

3. Open a Pull Request.

## Rules

- The work must be about **free space detection or traversability estimation** using learning-based or vision-based methods.
- Link the **official** paper page (arXiv, journal, or conference) and the **official** code repository.
- Use `—` for the Code column if no code is released. Do not link unofficial re-implementations without marking them as such.
- Keep entries sorted so that newer works appear lower in each table.
- One entry per Pull Request is preferred.
